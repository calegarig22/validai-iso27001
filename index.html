    Prepare o app uma vez: chave da IA e normas. Depois, qualquer pessoa com o link usa sem configurar nada.

    Onde fica cada coisa

    Tudo fica no seu servidor (Vercel + Neon). Só vai para o Google (Gemini) o que é preciso durante a análise.

    ItemOnde fica
    Chave do GeminiNo servidor. Nunca chega ao navegador de quem usa o app.
    Normas ISO (texto)No servidor. Quem usa o app vê só números e títulos; o texto vai ao Gemini durante a análise.
    Documento avaliadoFica na tela; vai ao Gemini (pelo servidor) durante a análise. Não é guardado.
    Políticas cruzadasFicam na tela; vão ao Gemini (pelo servidor) durante o cruzamento. Não são guardadas.
    Achados do cruzamentoNo banco Neon (tabela própria), compartilhados: todos com o link veem. Só o Admin apaga.
    Resultados (histórico)No banco Neon, compartilhado: todos com o link veem. Só o Admin apaga.
